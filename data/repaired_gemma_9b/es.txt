Ejecutar %1
Seleccione si se debe habilitar la programación en tiempo real para la aplicación. El programador determina qué proceso se ejecutará y cuál tendrá que esperar. Hay dos programadores disponibles: Normal: Este es el programador estándar de uso compartido de tiempo. Dividirá de manera justa el tiempo de procesamiento disponible entre todos los procesos. Tiempo real: Este programador ejecutará su aplicación sin interrupciones hasta que libere el procesador. Esto puede ser peligroso. Una aplicación que no libera el procesador puede colgar el sistema. Necesita la contraseña de root para usar el programador.

Para que el renderizado de subpíxeles funcione correctamente, necesitas saber cómo están alineados los subpíxeles de tu pantalla. En las pantallas TFT o LCD, un solo píxel está compuesto realmente por tres subpíxeles, rojo, verde y azul. La mayoría de las pantallas tienen un ordenamiento lineal de subpíxeles RGB, algunas tienen BGR. Esta función no funciona con monitores CRT.

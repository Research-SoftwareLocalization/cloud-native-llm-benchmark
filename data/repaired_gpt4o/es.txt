Cursor ocupado
El cursor ocupado de KDE ofrece un cursor ocupado para la notificación de inicio de la aplicación. Para habilitar el cursor ocupado, seleccione un tipo de retroalimentación visual del combobox. Puede ocurrir que algunas aplicaciones no sean conscientes de esta notificación de inicio. En este caso, el cursor deja de parpadear después del tiempo indicado en la sección 'Tiempo de espera de indicación de inicio'.

Esta opción fuerza un valor específico de DPI para las fuentes. Puede ser útil cuando el DPI real del hardware no se detecta correctamente y también se utiliza a menudo de manera incorrecta cuando se usan fuentes de mala calidad que no se ven bien con valores de DPI distintos de 96 o 120 DPI. El uso de esta opción se desaconseja en general. Para seleccionar un valor de DPI adecuado, una mejor opción es configurarlo explícitamente para todo el servidor X si es posible (por ejemplo, DisplaySize en xorg.conf o añadiendo -dpi value a ServerLocalArgs= en $KDEDIR/share/config/kdm/kdmrc). Cuando las fuentes no se renderizan correctamente con el valor de DPI real, se deben usar fuentes mejores o se debe verificar la configuración de la sugerencia de fuentes.
